# GitHub Webhook PR Automation Setup Guide

This guide explains how to set up GitHub webhook automation with Gemini AI for automated PR code reviews in your NIT Manipur Placement project.

## 📋 Prerequisites

1. **Gemini API Key** - Get from [Google AI Studio](https://aistudio.google.com/app/apikeys)
2. **GitHub Token** - Create a Personal Access Token from [GitHub Settings](https://github.com/settings/tokens)
3. **Your Server Running** - The Node.js server must be accessible from the internet for webhooks

## 🚀 Step 1: Install Dependencies

```bash
cd server
npm install
```

This will install the Gemini AI SDK (`@google/generative-ai`) and other dependencies.

## 🔑 Step 2: Set Up Environment Variables

1. Copy the example file:
```bash
cp server/.env.example server/.env
```

2. Update `.env` with your credentials:
```env
# Get from https://aistudio.google.com/app/apikeys
GEMINI_API_KEY=your_gemini_api_key_here

# Create from https://github.com/settings/tokens
# Scopes needed: repo, read:repo_hook
GITHUB_TOKEN=your_github_personal_access_token

# Use any random string (at least 32 characters recommended)
GITHUB_WEBHOOK_SECRET=your_secure_webhook_secret_key_12345

# Other existing configs...
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=password
DB_NAME=placement_db
PORT=3000
```

### Getting the Required Tokens:

**Gemini API Key:**
- Go to https://aistudio.google.com/app/apikeys
- Click "Create API Key"
- Copy and paste into `.env`

**GitHub Personal Access Token:**
- Go to https://github.com/settings/tokens
- Click "Generate new token (classic)"
- Select scopes: `repo`, `read:repo_hook`
- Copy and paste into `.env`
- Choose a secure webhook secret (any random string)

## 🔧 Step 3: Configure GitHub Webhook

Once your server is running (and accessible from the internet):

1. Go to your repository settings: `https://github.com/alokrajhans/nit-manipur-placement/settings/hooks`
2. Click "Add webhook"
3. Fill in the webhook settings:
   - **Payload URL**: `https://your-server-domain.com/webhook/github`
   - **Content type**: `application/json`
   - **Secret**: Use the same value as `GITHUB_WEBHOOK_SECRET` in `.env`
   - **Events to trigger**: Select "Let me select individual events"
   - Check: ✅ **Pull requests**
4. Click "Add webhook"

### For Local Development:

If testing locally, you can use **ngrok** to expose your local server:

```bash
# Install ngrok
# https://ngrok.com/download

# Run ngrok to expose localhost:3000
ngrok http 3000

# Use the provided URL (e.g., https://xyz123.ngrok.io) as your Payload URL
# Webhook URL: https://xyz123.ngrok.io/webhook/github
```

## 🏃 Step 4: Run the Server

```bash
cd server
npm run build
npm start
```

Or in watch mode during development:
```bash
npm run build:watch &
npm start
```

## 📝 Step 5: Test the Webhook

Create a test PR in your repository:

1. Create a feature branch
2. Make some changes
3. Push and create a Pull Request
4. Wait a few seconds...
5. The webhook should:
   - Receive the PR event
   - Send the PR details to Gemini AI
   - Post an automated code review comment on your PR

## 🎯 What the Webhook Does

When a PR is opened/updated:

1. **Receives GitHub Event** - Webhook endpoint receives PR event
2. **Fetches Changed Files** - Uses GitHub API to get file diffs
3. **Analyzes with Gemini** - Sends code to Gemini AI for analysis
4. **Generates Review** - AI generates:
   - Summary of changes
   - Improvement suggestions
   - Testing recommendations
   - Security concerns
5. **Posts Comment** - Adds automated review as PR comment

## 🔍 Troubleshooting

### Webhook not receiving events:
- Check webhook URL is accessible from the internet
- Verify firewall isn't blocking incoming requests
- Check GitHub webhook delivery history: Settings > Webhooks > Click webhook > Recent Deliveries

### Gemini API errors:
- Verify `GEMINI_API_KEY` is correct
- Check API quota at https://aistudio.google.com/app/apikeys
- Ensure API is enabled

### GitHub Token errors:
- Verify token has correct scopes (`repo`, `read:repo_hook`)
- Check token hasn't expired
- Verify token permissions in GitHub settings

### Webhook signature verification fails:
- Ensure `GITHUB_WEBHOOK_SECRET` matches GitHub webhook secret exactly
- Secret is case-sensitive
- Try disabling signature verification temporarily to debug (not recommended for production)

## 🛡️ Security Considerations

1. **Never commit `.env`** - Use `.env.example` as template
2. **Webhook Secret** - Use a strong, random secret (GitHub generates one for you)
3. **GitHub Token** - Restrict to minimal required scopes
4. **API Keys** - Regenerate if exposed
5. **Signature Verification** - Always verify webhook signatures in production
