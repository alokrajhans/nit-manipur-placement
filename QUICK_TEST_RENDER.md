### 2. Configure GitHub App Webhook

1. Go to: https://github.com/settings/apps
2. Click on your GitHub App
3. Set **Webhook URL** to:
   ```
   https://nit-manipur-placement-1.onrender.com/github-app/webhook
   ```
4. Make sure **Webhook Secret** is set (copy the secret)
5. Click "Save"

**Events to Subscribe:**
- [x] Pull requests
- [x] Pull request reviews

---

### 3. Install App on Test Repository

1. Go to your GitHub App settings
2. Click "Install App"
3. Select a test repository (or create a new one)
4. Click "Install"

```bash
git add .
```

```bash
git push origin test/gemini-pr-review
```

**Result:** Bot analyzes all files

---

### Scenario 2: Large PR (Many Lines Changed)
```bash
# Generate large file
python3 << 'EOF'
with open('large-file.js', 'w') as f:
    for i in range(100):
        f.write(f"function func{i}() {{\n  console.log('test {i}');\n}}\n")
EOF

git add large-file.js
git commit -m "Add large file with multiple functions"
git push origin test/gemini-pr-review
```

**Result:** Bot analyzes complexity and suggests improvements

---

```bash

git push origin test/gemini-pr-review
```

**Result:** Bot updates review (or skips if already reviewed)

## Troubleshooting

### Bot Not Commenting?

**Check 1: Is webhook reaching server?**
```bash
# Check Render logs for incoming webhooks
# Should see: "📨 Processing opened event"
```

**Check 2: Are credentials valid?**
```bash
# Verify on Render Environment variables
# GOOGLE_API_KEY - valid Gemini key?
# GITHUB_APP_PRIVATE_KEY - correct format?
```

**Check 3: Is webhook secret correct?**
```bash
# Render logs should show signature verification
# Look for: "❌ Invalid webhook signature"
```

### Gemini Error?

**Check API Key:**
- Go to: https://console.cloud.google.com
- Enable Generative AI API
- Generate new API key if needed
- Update in Render Environment

### GitHub API Error?

- Check GITHUB_APP_PRIVATE_KEY format (should include `\n` for newlines)
- Verify app is installed on the repository
- Check rate limits (1-second delay built-in)
